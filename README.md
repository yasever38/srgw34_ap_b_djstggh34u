# Бюджет

Личный финансовый план в виде простого приложения: внёс доход — получил готовое распределение по категориям с точностью до копейки.

Работает как PWA: ставится на телефон, открывается без интернета, все данные лежат у вас.

---

## Как это работает

Алгоритм «водопада»: доход делится по порядку — то, что осталось, уходит дальше.

1. Благотворительность — 1%
2. ИИС — фиксированная сумма
3. ПДС — фиксированная сумма
4. Остаток → «На жизнь» 70% / «Свободный остаток» 30%
5. Свободный остаток → «Подушка» 30% / «Агрессивные накопления» 70%

Суммы считаются до копейки и всегда сходятся: сколько зашло дохода, столько и распределено — без «потерянных» рублей.

## Как пользоваться

- **Доходы** — вносите каждый доход, даже небольшой, с датой и комментарием.
- **Главная** — диаграмма, «Доход за месяц» и раскладка «Как делится доход». Переключайтесь между месяцами.
- **Настройки** — меняйте проценты и суммы, переименовывайте категории, добавляйте свои. Проценты не дадут превысить 100%; фикс-суммы, вылезшие за доход месяца, подсветятся красным.
- **Инфо** — справка по ИИС-3 и ПДС, календарь действий с галочками «сделано» и долгосрочный план на 15 лет.

Правило: заходите в приложение хотя бы раз, обязательно 27 числа, и вносите каждый доход.

## Установка (PWA)

1. Откройте приложение в браузере.
2. В Chrome/Android: меню → «Установить приложение». В iPhone Safari: «Поделиться» → «На экран "Домой"».
3. После установки работает офлайн и выглядит как обычное приложение.

## Данные и резервные копии

- Всё хранится локально в браузере (LocalStorage).
- **Настройки → Экспорт JSON** — сохраните файл как бэкап.
- **Импорт JSON** — вернёт всё состояние из файла (категории, проценты, доходы, галочки).
- Переносите между устройствами через эти файлы. Держите бэкап в надёжном месте.

## Запуск

Файл `index.html` открывается напрямую (двойной клик) или через любой статический сервер:

```
npx serve .
```

Никакой сборки и зависимостей — один файл.
