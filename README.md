# Бюджет — личный трекер доходов, трат и накоплений

Мобильное веб-приложение (PWA) для ведения личного бюджета: учёт зарплаты,
распределение по категориям трат, расчёт накоплений и их распределение по
инструментам (вклады, облигации, металлы, бизнес, активы).

Работает прямо в браузере, без сервера и без интернета после первого
открытия. Все данные хранятся только на твоём телефоне.

## Как открыть как приложение

1. Открой ссылку этого GitHub Pages сайта в Chrome на Android
2. Меню ⋮ → **«Установить приложение»** / **«Добавить на главный экран»**
3. Готово — иконка на главном экране, открывается на весь экран

## Вкладки

### 💰 Доходы
- Добавляешь зарплату за месяц (название месяца + сумма)
- Сводка: средняя ЗП за всё время, средняя за последние 4 месяца, сумма
  за всё время, количество учтённых месяцев
- Здесь же — **резервная копия** (см. раздел ниже)

### 🧾 Траты
- **Буфер** — фиксированная сумма на жизнь в месяц (не зависит от размера
  ЗП — это специально, чтобы расходы не росли вслед за доходом)
- **Категории** — на что уходит буфер, в процентах. Сумма всех категорий
  должна быть равна 100% (если нет — появится предупреждение)
- **Спортзал/бассейн/сауна** — отдельная категория, показывает, сколько
  набегает в год при текущем проценте
- **Благотворительность** — считается не от буфера, а от полной ЗП
  (отдельный процент)
- Статистика: сколько потрачено всего, сколько ушло в накопления

### 🏦 Счета
- Схема движения денег за последний месяц: зарплата → буфер →
  траты + подушка, и отдельно → благотворительность и накопления
- Таблица "сколько и куда положить в этом месяце"

### 📈 Накопления
- Распределение всех накопленных денег по группам: надёжные (вклады,
  облигации, юань), защитный резерв (металлы), агрессивные (бизнес,
  активы)
- Ставки доходности и проверка, насколько процентный доход покрывает
  возможную просадку агрессивной части
- Распределение накоплений именно за последний месяц

## Резервная копия данных (важно!)

Все данные хранятся в памяти браузера (localStorage), привязаны к этому
сайту и этому телефону. Это означает:

- Обновление кода на GitHub **не трогает** сохранённые данные
- Но очистка кэша Chrome, удаление приложения через системные настройки
  или сброс телефона **может стереть всё**

**Поэтому:** после важных изменений (внёс новую зарплату, поменял
проценты) заходи во вкладку **«Доходы»** → блок **«Резервная копия»** →
жми **«Экспорт JSON»**. Скачается небольшой файл — сохрани его в Google
Диск, Telegram «Избранное» или любое облако.

Если данные пропали — **«Импорт JSON»** в том же блоке, выбери
сохранённый файл, всё восстановится за секунду.

Рекомендация: делай экспорт хотя бы раз в месяц, после внесения зарплаты.

## Обновление приложения

Когда нужно внести изменения в логику или дизайн:

1. Замени файл `index.html` в репозитории на новую версию
2. Подожди 1-2 минуты, пока GitHub Pages пересоберёт сайт
3. На телефоне просто обнови страницу в Chrome (или переоткрой
   установленное приложение) — новый код подхватится автоматически,
   данные останутся на месте

Менять иконку (`icon-192.png`, `icon-512.png`) или название
(`manifest.json`) — нужно после этого **переустановить ярлык** на
главном экране (удалить старый, добавить заново), иначе Android
покажет закэшированную старую иконку.

## Структура файлов в репозитории

```
index.html       — само приложение (вся логика и интерфейс)
manifest.json     — настройки PWA (название, иконки, цвета)
icon-192.png      — иконка для главного экрана
icon-512.png      — иконка для главного экрана (увеличенная)
README.md         — этот файл
```
